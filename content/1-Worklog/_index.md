## 12-Week Internship Worklog Overview

During my **12-week** internship in the **First Cloud AI Journey (FCAJ)** program (starting from **September 14, 2026** through early **December 2026**), I completed structured weekly hands-on labs, real-world AWS console & CLI deployments, Infrastructure as Code (CloudFormation/CDK) projects, containerized & serverless architectures, and a final team capstone (**Smart Kitchen / Bếp Thông Minh**).

### How I Completed the Worklog

- **Structured Weekly Cadence (Mon–Sat):** Each week focused on a cohesive cloud domain, progressing logically from foundational AWS setup and networking in Weeks 1–3, security and operations in Weeks 4–6, automation/serverless/containers in Weeks 7–10, to enterprise migration and data analytics in Weeks 11–12.
- **Hands-On Verification:** Nearly every exercise was deployed and tested in a live AWS account (`us-east-1` / `ap-southeast-1`) using AWS Management Console, AWS CloudShell, AWS CLI, `kubectl`, Docker, Python, and Terraform/CDK, backed by screenshots, log captures, and troubleshooting notes.
- **Documentation & Reflection:** At the end of each week, I compiled step-by-step architectures, key CLI commands, encountered issues, and resolutions in both English and Vietnamese to build a reusable technical reference.
